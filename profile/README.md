# NingZeStudio

> 专注中文 Minecraft 生态建设

你好！我们是 **柠泽工作室**（NingZeStudio），一个致力于提升中文 Minecraft 社区体验的开发团队。

**关于我们**
- 成员：@柠枺、@梦泽（均来自中国）

**开源项目**

**🔹 Lemwood Mirror**
> 面向 Minecraft 启动器、服务端及插件的镜像加速服务

基于 Go 与 Vue 构建，为中文玩家提供更稳定的资源下载体验。
- GitHub: [NingZeStudio/lemwood-mirror](https://github.com/NingZeStudio/lemwood-mirror)

**🔹 McLogs-Next**
> 新一代 Minecraft 服务器日志分析解决方案

| 组件 | 定位 |
|:---|:---|
| [McLogs-Next-API](https://github.com/NingZeStudio/McLogs-Next-API) | Headless API 主服务 |
| [McLogs-Next-UI](https://github.com/NingZeStudio/McLogs-Next-UI) | 官方开源的Web UI |
